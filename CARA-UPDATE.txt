KITA-KITA UNDANGAN — UPDATE KHUSUS CONTOH ROYAL
==================================================

ISI ZIP
- royal.html : halaman Royal yang dibuat berdasarkan video referensi, gambar dan musik sudah tertanam di dalam file.
- PRATINJAU-ROYAL-SAMPUL.png : pratinjau tampilan sebelum dibuka.
- PRATINJAU-ROYAL-DALAM.png : pratinjau setelah tombol Buka Undangan.
- PRATINJAU-MEMPELAI.png : pratinjau bagian Mempelai.

CARA MELIHAT TANPA MENGUBAH WEBSITE
1. Ekstrak ZIP di laptop atau HP.
2. Buka file royal.html menggunakan browser (Chrome, Safari, dll).
3. Klik gambar tombol "Buka Undangan" pada sampul.
4. Gulir ke bawah. Klik tombol musik untuk menyalakan atau mematikan.

CARA MENGGANTI CONTOH ROYAL DI WEBSITE
1. Simpan cadangan royal.html lama dari repo GitHub yang terhubung ke hosting.
2. Masuk GitHub proyek Kita-Kita Undangan.
3. Ganti HANYA file royal.html di folder yang sama dengan royal.html lama.
4. Commit perubahan ke branch yang dipakai deploy.
5. Jika hosting tersambung otomatis ke GitHub, tunggu build/deploy berhasil. Jika tidak tersambung otomatis, lakukan deploy sesuai konfigurasi hosting yang sekarang.
6. Buka https://dark-mode-166a.najarrudi74.workers.dev/royal.html lalu refresh jika masih menampilkan versi tersimpan.
